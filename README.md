# lukaspriess.de

Die Seite unter `https://lukaspriess.de`: ein Gorilla mit Mittelfinger, als Spaß (`gorilla.jpg`, vom Inhaber der Seite gestellt). Reine
statische Seite (`index.html`), ausgeliefert über GitHub Pages vom Branch `seite`.

- `CNAME` nennt die Domain. Im DNS zeigen vier A-Einträge der Hauptdomain auf GitHub Pages.
- Suchmaschinen sollen die Seite nicht aufnehmen (`noindex`).
- Subdomains haben eigene Repos (`auto.lukaspriess.de`: `auto-schluessel`).
